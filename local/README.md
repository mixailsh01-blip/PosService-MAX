# Локальный запуск SPRT API

Нужен Docker Desktop (или OrbStack) на вашем компьютере.

    cd local && ./start.sh

- Приложение: http://localhost:3080
- Вход: введите любую почту; ссылку для входа откройте в «почте» http://localhost:8025
  (локально вход через Pyrus отключён: переменные PYRUS_* не заданы, а письма никуда не уходят).
- «Обучение» и «Яндекс Еда» берутся из папок `learn-app/` и `yandex-app/` репозитория: правите файл,
  обновляете страницу, видите результат.
- Остановить: `docker compose down` (данные сохраняются), удалить данные: `docker compose down -v`.
- Если образ не скачивается (доступ запрещён): `docker login ghcr.io` с токеном GitHub (право read:packages).
- Образ собран под Intel/AMD; на Mac с чипом Apple он работает через эмуляцию, чуть медленнее.

Правки самого интерфейса (Vue-код в патче) требуют пересборки образа, это те же 15 минут в GitHub Actions.
Всё, что лежит в `learn-app/` и `yandex-app/`, перестраивать не нужно.
